# PrakticaBPMN
Данный репозиторий состоит из следующих работ:
## BPMN.png
реализованная диаграмма с помощью сайта https://bpmn-io-demo-staging.herokuapp.com/new

На диаграмме BPMN-диаграмма бизнес-процесса работы пассажира и авиакомпании с билетом. Схема разделена на две дорожки ("Пассажир" и "Авиакомпания") содержит стартовые/конечные события, задачи (поиск билета, выбор рейса, проверка мест, создание бронирования, оплата, выписка билета), шлюзы (условия "есть места", "оплата получена"), ветвление с отменой бронирования при отказе или отсутствии оплаты
